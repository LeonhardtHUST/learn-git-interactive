# 第 4 章 服务器上的 Git（明确说明 / 暂未提供交互实验）

本章对应《Pro Git》第二版第 4 章，介绍「把 Git 仓库放到服务器上」所需的协议与仓库形态。

## 关键概念

- **传输协议**
  - 本地协议（`file://` 或直接使用路径）：同一台机器上多个仓库之间协作，最简单。
  - SSH：最常用，加密且自带鉴权，远程 URL 形如 `git@host:path/repo.git`。
  - HTTPS：穿透防火墙友好，但每次通常需输入凭据（可用凭据助手缓存）。
  - Git 协议（9418 端口，无鉴权）：只读、速度最快，生产少用。
- **bare 仓库**：没有工作区的仓库（没有工作目录，只有 `objects/` 与 `refs/`），专门作为「中枢」供他人推送/拉取。创建方式 `git init --bare`。
- **在服务器上托管**：可自建（SSH + bare 仓库 + 受控用户），或使用 GitHub / GitLab / Gitea 等。
